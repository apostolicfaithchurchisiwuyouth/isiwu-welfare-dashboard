Install AFC Isiu

Chrome may not always show the automatic installation prompt. You can still install the AFC Isiu Youth Portal manually.

1

On Google Chrome

Open the Chrome menu using the ⋮ button in the top-right corner.

⋮ Look for Install app or Add to Home screen .
2

On Android

Tap the Chrome menu and choose Install app or Add to Home screen .

3

On iPhone or iPad

Open the portal in Safari, tap the Share button, then choose Add to Home Screen .

4

On a computer

In supported browsers, look for the Install icon in the address bar or open the browser menu and choose Install AFC Isiu Youth Portal .

Once installed, the portal will open like an app without requiring you to return to the browser each time.
