Install AFC Isiu Youth Portal

Add the portal to your home screen.

1

Android / Chrome

Open AFC Isiu Youth Portal in Chrome. Tap the browser menu and choose Install app or Add to Home screen .

Browser menu
2

iPhone / iPad

Open the portal in Safari. Tap the Share button, then select Add to Home Screen .

3

Computer

In a supported browser such as Chrome or Edge, look for the Install icon in the address bar or browser menu.

Important: A PWA must be installed through the browser's installation system. The website cannot silently install an application without your confirmation.
